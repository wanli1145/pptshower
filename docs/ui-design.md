# 课件库界面设计

## 目标与参考

为教师在桌面浏览器中快速选取课件、在课堂中专注展示而设计；手机宽度下保留搜索、管理入口和展示操作。保留纯静态架构及既有加密格式。

2026-10-18 查看了以下公开参考：

- 主参考：[Tabler Dashboard](https://preview.tabler.io/)。借鉴浅色工作区、明确的导航层级、边框分隔、表单和状态组织。
- 辅参考：[shadcn Authentication](https://ui.shadcn.com/examples/authentication)。仅借鉴品牌介绍与表单分栏的结构。
- 类别参考：[Pitch](https://pitch.com/)。确认以课件为中心的产品表达；不引入其编辑器、AI 功能或营销流程。

Refero MCP 返回订阅不可用，改为直接浏览公开模板，并查看实际渲染。没有下载或复制模板源码。

## 固定设计方向

主方向是结构清晰的工作空间：浅灰背景、白色内容面、细边框和克制的间距。品牌区域沿用深色对比，使用深绿与浅绿色课件图形；正文使用系统字体，不引入远程字体请求。

| 决策 | 来源与用途 | 实现 |
| --- | --- | --- |
| 导航与内容区分离 | Tabler 的信息层级，适用于课件选择与管理 | 深色侧栏，浅色工作区，共享管理台布局 |
| 解锁页左右分栏 | shadcn 认证模板的结构 | 左侧品牌和简单幻灯片图形，右侧单一解锁任务 |
| 绿色主要按钮 | 本项目的可辨识操作色 | `#16735d` 用于主要动作，危险动作保持红色 |
| 课件封面 | 现有仅含标题和日期的加密索引 | 根据已解密标题生成文字封面，不冒充 PDF 缩略图 |
| 黑色展示舞台 | 课堂投影场景与已有播放器 | 播放器独立深色变量，控件可以隐藏 |
| 搜索、排序和视图切换 | 多套课件的选择需求 | 纯客户端过滤；锁定时清除搜索和解密列表 |
| 手机单列 | 表单可读性与触控需求 | 760px 以下折叠侧栏、表单与卡片单列排列 |

不加入虚构统计、用户头像、无功能导航或外部运行时依赖。封面装饰只是简单 CSS 几何形状，不要求位图素材。

## 验证范围

自动化测试覆盖加密完整性、基于固定提交的保存、旧索引拒绝、保存期间的并发冲突、原子删除和权限错误传播。浏览器验证使用隔离模拟仓库；不替代真实 GitHub 权限和 Pages 部署测试。
