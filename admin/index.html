GETTING STARTED

第一次连接？

在 GitHub 创建仅用于此仓库的令牌。

  1. 1

    进入 Settings → Developer settings → Personal access tokens → Fine-grained tokens。

  2. 2

    Repository access 仅选择 wanli1145/pptshower。

  3. 3

    Contents 设为 Read and write，Metadata 保持只读。

  4. 4

    复制令牌，粘贴到左侧并连接。
