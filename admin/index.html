连接仓库

管理台需要一次性获得对 wanli1145/pptshower 仓库的写入权限。 令牌只保存在本浏览器的 localStorage 中，不会上传到其他地方。

如何创建令牌
  1. 打开 GitHub 的 Settings → Developer settings → Personal access tokens → Fine-grained tokens。
  2. 把 Repository access 设为仅 wanli1145/pptshower。
  3. 在 Repository permissions 中把 Contents 设为 Read and write，Metadata 保持只读。
  4. 生成后把令牌粘贴到上面的输入框。令牌只会被本页面用于读写这个仓库。

输入总口令

总口令只在当前页面内存中用于加密和解密课件索引，刷新页面后需要重新输入。

初始化站点

仓库已连接，但站点还没有总口令。请设置一个至少 12 个字符的总口令。 口令不会保存在任何地方，忘记后将无法解密任何课件。
